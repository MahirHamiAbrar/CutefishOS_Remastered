# Cutefish OS Remastered

Before doing anything, read `.claude/memories/README.md`: the project's memory
(what was done, what's tested, what's left, the user's rules, known traps).
Keep it current: when you finish a piece of work, update `status.md`,
`timeline.md` and `next-steps.md` there, and log setbacks in `docs/setbacks.md`.

Hard rules: stay inside this folder; ask the user about choices that are theirs;
never `git add src/` (recreate it with `scripts/fetch.sh`); commit and push often.
